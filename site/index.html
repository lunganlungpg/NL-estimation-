Watch nonlinear least squares find the answer

Fitting a curve like y = V·x / (K + x) means searching for the parameters that minimise the sum of squared errors. Nobody can solve that in one step, so solvers walk downhill. Pick a starting point on the error landscape below and watch the two classic algorithms, Gauss–Newton and Levenberg–Marquardt, race to the minimum. One of them sometimes falls off a cliff.

02How it works

Both methods solve \min_\theta S(\theta)=\sum_i r_i(\theta)^2,\; r_i=f(x_i,\theta)-y_i by replacing the curve with a straight-line (tangent) approximation around the current guess, solving that easy linear problem, and repeating.

Gauss–Newton

Linearise with the Jacobian J_{ij}=\partial f(x_i,\theta)/\partial\theta_j:

f(x,\theta+\delta)\approx f(x,\theta)+J\delta

Minimising the linearised SSE gives the normal equations:

(J^\top J)\,\delta = -J^\top r

Near the solution this converges very fast (almost quadratically when residuals are small). Far away, the tangent approximation is poor, the step can overshoot, and the method can diverge. Step halving (Hartley, 1961) shortens a step until the SSE decreases.

Levenberg–Marquardt

Add a damping term \lambda D with D=\operatorname{diag}(J^\top J):

(J^\top J+\lambda D)\,\delta = -J^\top r

Small λ gives the Gauss–Newton step. Large λ gives a short step along the steepest-descent direction -J^\top r. After each trial step, the gain ratio

\rho=\frac{S(\theta)-S(\theta+\delta)}{S(\theta)-\|r+J\delta\|^2}

compares the actual with the predicted improvement. If ρ is good, accept the step and lower λ; if not, reject it and raise λ. That is a trust region in disguise.

When do we stop?

This site and the nlsfit package use the relative offset of Bates & Watts (1981), as R's nls does: the share of the residual vector that lies in the model's tangent plane. It is 0 at an exact minimum and does not depend on parameter scale, unlike "step is small" tests that can stop too early.

Uncertainty

At the solution, \widehat{\operatorname{Cov}}(\hat\theta)=s^2(J^\top J)^{-1}, s^2=S(\hat\theta)/(n-p). Wald intervals use ±t·SE. Profile-likelihood intervals follow the true curvature and can be asymmetric. The package offers both, plus bootstrap.

Starting values matter

Both methods find a local minimum near the start. Use sensible starts (from a linearising transform, a plot or domain knowledge), and try several. On NIST MGH09, pure Gauss–Newton converges to a different local minimum.

06Use it in Python

The nlsfit package contains the same algorithms, implemented readably, plus everything you need to report a fit.

# pip install "git+https://github.com/lunganlungpg/NL-estimation-.git"
import nlsfit

data = nlsfit.datasets.load("puromycin")
res = nlsfit.fit(nlsfit.models.michaelis_menten, data.x, data.y, method="lm")  # or "gn"
print(res.summary())                    # estimates, SE, t, p, CI, σ, R², AIC
res.conf_int(method="profile")             # profile-likelihood intervals
res.predict(x_new, interval="prediction")  # bands
